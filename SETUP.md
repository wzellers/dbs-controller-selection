Everything is here. The Python modules, datasets and MATLAB model were copied straight
from `~/UNC/Research/Code/will-code/will-code-current/workspace`, and all of it was checked
for absolute paths, credentials and authorship headers — clean.

`bgn_vars.mat` is excluded on purpose: it is regenerated by `bgn_init` on every run, and
the copy in the workspace root is 380 MB.

## Create the repo and push

    cd dbs-controller-selection
    git init
    git add .
    git status          # read this list before committing
    git commit -m "Per-severity reward models and T3P sweeps for DBS controller selection"

    gh repo create dbs-controller-selection --private --source=. --push

`git status` before the first commit is the one step not to skip — it is the last chance to
catch `bgn_vars.mat` or a stray cache before it is in the history.

Make it private first. Loosen it later if Arka wants it public.
